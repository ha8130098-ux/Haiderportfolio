## 🚀 Live Demo & Deployment

This project is a self-contained, zero-dependency static website. It can be deployed instantly for free using **GitHub Pages**, **Vercel**, **Netlify**, or standard web hosting.

### 🌐 Deploy with GitHub Pages:
1. Create a new GitHub repository (e.g., `haider-abbas-portfolio` or `haiderabbas.github.io`).
2. Upload `index.html` (and `README.md`) to the repository.
3. Go to **Settings** > **Pages**.
4. Under **Branch**, select `main` (or `master`) and `/ (root)`, then click **Save**.
5. Your site will be live at `https://<your-username>.github.io/<repo-name>/` in ~60 seconds!
